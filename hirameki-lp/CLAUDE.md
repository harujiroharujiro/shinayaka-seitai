> このファイルは Claude Code のプロジェクトフォルダに `CLAUDE.md` として置いて使います。

## 1. 案件の前提（架空のクライアント設定）

| 項目 | 内容 |
|---|---|
| 教室名 | ひらめきコード教室 学園前校 |
| 所在地 | 奈良県奈良市・近鉄学園前駅 徒歩4分 |
| 対象 | 小学1年生〜中学3年生 |
| 開校 | 2021年 |
| 規模 | 1クラス最大6名、在籍生徒 約80名 |
| 強み | 少人数制／年2回の作品発表会／毎回の学習報告をLINEで保護者に送付 |
| LPのゴール | **無料体験会の予約**（サブ：LINEでの相談） |

### 誰に向けたLPか

- **読む人（決める人）**：小学生の子どもを持つ30〜40代の保護者。スマホで、夜や移動中に読む
- **通う人**：ゲームやYouTubeが好きな子ども
- **保護者の主な不安**
  - ゲームばかりで、このままでいいのか不安
  - 学校でプログラミングが必修になったが、家では教えられない
  - パソコンを触ったことがなくてもついていけるか
  - 習い事として続くか、何が身につくのかわからない
  - 料金・送迎・振替はどうなっているか

### 読み終えたときに思ってほしいこと

「ゲーム好きを"つくる力"に変えられそう。まずは体験に行ってみよう」

## 2. ページ構成とコピー

各セクションの **目的** を守ることが最優先。コピーは下記をそのまま使い、調整が必要なら提案してから変更すること。

### ① ファーストビュー
- **目的**：3秒で「誰向けの・何の教室で・次に何をすればいいか」が伝わる
- 小見出し：小学1年生〜中学3年生のプログラミング教室
- キャッチ：**ゲームで「遊ぶ」子から、ゲームを「つくる」子へ。**
- サブ：はじめてでも大丈夫。1クラス6名までの少人数で、一人ひとりのペースに合わせて教えます。
- 数字（3つ並べる）：在籍 約80名／体験後の入会率 82%／保護者満足度 4.8 / 5
- CTA：**無料体験会に申し込む**（サブボタン：LINEで相談する）
- CTAの近くに「次回の体験会：毎週土曜 10:00／14:00」と開催日を小さく表示
- 近鉄学園前駅 徒歩4分 の表記

### ② 保護者のお悩み（共感）
- **目的**：「うちのことだ」と思ってもらう
- 見出し：こんなこと、思っていませんか？
- チェックリスト形式で4項目（上記「保護者の主な不安」から）
- 締め：その「好き」は、伸ばし方しだいで一生ものの力になります。

### ③ 教室の特徴（3つ）
- **目的**：他の教室ではなく、ここを選ぶ理由を示す
1. **6名までの少人数制**：講師が全員の画面を見られる人数。わからないまま置いていかれません。
2. **毎回、LINEで学習報告**：今日つくったもの・できるようになったことを写真つきでお届け。家での会話が増えます。
3. **年2回の作品発表会**：自分の作品を人前で発表する経験が、自信と伝える力を育てます。

- 特徴の直後に、ページ途中のCTAを1つ置く（「まずは体験で、教室の雰囲気を見てください」＋ボタン）

### ④ コース紹介
- **目的**：子どもの年齢・レベルに合うコースがあると分かってもらう
| コース | 対象 | 内容 | 使う教材 |
|---|---|---|---|
| はじめてコース | 小1〜小3 | ブロックを並べて動かす楽しさを知る | Scratch Jr. ／ Scratch |
| ゲームづくりコース | 小3〜小6 | 自分で考えたゲームを完成させる | Scratch ／ マインクラフト |
| テキストコース | 小5〜中3 | 文字でプログラムを書く、本格的な一歩 | Python |

### ⑤ 生徒の作品
- **目的**：「うちの子もこんなものが作れるようになる」と想像してもらう
- 作品カード3枚（画像＋作品名＋学年＋ひとこと）
  - 「にげろ！ネコ迷路」小2
  - 「宇宙シューティング」小5
  - 「天気でコーデを教えてくれるアプリ」中1

### ⑥ レッスンの流れ（90分）
- **目的**：通ったときの様子を具体的にイメージしてもらう（順番に意味があるので番号付き）
1. 前回のふりかえり（10分）
2. 今日のテーマを学ぶ（20分）
3. 自分の作品づくり（50分）
4. 発表・おうちの方への報告（10分）

### ⑦ 保護者の声
- **目的**：第三者の声で不安を消す
- 3件（学年・続けている期間を添える）。**ポートフォリオ掲載時は「※架空の作品のためサンプルです」と明記する**

### ⑧ 料金
- **目的**：料金の不安をなくし、比較しやすくする
- 入会金 11,000円（体験会当日の申込で無料）
- 月謝：はじめて 8,800円／ゲームづくり 11,000円／テキスト 13,200円（すべて税込・月3回）
- パソコンは教室で無料貸出。振替は月1回まで可能
- 「はじめの1か月にかかる費用の例」を1行で示す（例：ゲームづくりコースを体験当日に申込→11,000円のみ）
- 料金の直後にもCTAを1つ置く

### ⑨ 講師紹介
- **目的**：「この人に任せたい」と思ってもらう
- 教室長1名＋講師1名。顔写真、名前、経歴、ひとこと

### ⑩ 無料体験会の流れ
- **目的**：申込のハードルを下げる
- 申込 → 確認のお電話 → 体験（60分）→ 保護者面談（15分）
- 開催日時：毎週土曜 10:00〜／14:00〜（各回3名まで）
- 「無理な勧誘はしません」を必ず明記

### ⑪ よくある質問
- **目的**：申込直前の最後の疑問を解消する
- アコーディオン形式で6問程度：パソコンを触ったことがない／送迎・駐輪場／振替／兄弟割引／いつから始めるべきか／何年で何ができるようになるか

### ⑫ 教室情報・アクセス
- **目的**：「通えるか」を判断してもらう（地域の教室では必須）
- 住所、地図（Googleマップ埋め込み）、開講曜日・時間、駐輪場あり／駐車場なし、電話番号

### ⑬ 最終CTA＋申込フォーム
- 見出し：まずは60分、体験してみませんか？
- フォーム項目：保護者名／お子さまの学年（選択）／希望日（第1・第2）／電話番号／メール／ご質問（任意）
- 「プライバシーポリシーに同意する」チェックボックス（必須）
- 送信後に完了メッセージを表示

### 全体共通
- **スマホでは画面下部に「無料体験に申し込む」ボタンを常に固定表示**
- ヘッダー：ロゴ、ページ内リンク（PCのみ）、CTAボタン
- フッター：教室名、運営会社名、住所、プライバシーポリシーへのリンク、コピーライト

## 3. デザインルール

### コンセプト
「方眼ノートとブロック」— 子どもの学習ノートの方眼と、ブロックプログラミングの角の丸いパーツを組み合わせる。子ども向けだが、**決めるのは保護者なので、幼すぎない・信頼感のある見た目**にする。

### 色（この5色以外は使わない）
| 役割 | 色 | 用途 |
|---|---|---|
| ベース | #FBFAF6 | 背景 |
| インク | #1E2A44 | 文字・見出し |
| メイン | #2F6FEB | ボタン以外の強調・リンク |
| CTA | #FF8A1F | 申込ボタンだけに使う。**ボタン文字は白ではなくインク色（#1E2A44）**にする（白文字だと読みにくい） |
| サブ | #FFD84D | マーカー・バッジなど小さな装飾 |

### フォント（Google Fonts）
- 見出し：M PLUS Rounded 1c（700・800）
- 本文：Noto Sans JP（400・700）
- 本文サイズ：スマホ16px／PC17px、行間1.8

### 余白・形
- 余白は 8px の倍数だけを使う
- セクションの上下余白：スマホ64px／PC112px
- 角丸：ボタンとカードは12px（ブロックパーツの形）、写真は16px
- 影は使いすぎない（カードは薄い枠線を基本にする）

### やらないこと
- 虹色・原色を多用する、いかにも「子ども向け」な配色
- 絵文字を見出しの飾りに使う
- 全部を中央揃えにする
- 1画面に CTA を2色以上で並べる

## 4. 技術仕様

- HTML / CSS / 最小限の JavaScript の1ページ構成（フレームワークなし）
- ファイル構成：`index.html`、`css/style.css`、`js/main.js`、`images/`
- 表示確認する幅：375px（スマホ）／768px（タブレット）／1280px（PC）
- 画像：WebP形式、`width` `height` `alt` を必ず指定、ファーストビュー以外は遅延読み込み
- フォーム：送信先は Formspree などの無料サービスを想定（初期段階は送信処理なしで完了表示だけでよい）
- SEO：`title`、`meta description`、OGP（SNSでシェアされたときの画像とタイトル）、favicon
- アクセス解析：GA4 のタグを入れる場所だけ用意しておく
- 公開先：Vercel

### 写真について
- 制作中は灰色のダミー枠に「ここに〇〇の写真」と書いておく
- 差し替えは、商用利用可能なフリー素材（Unsplash、ぱくたそ等）か、AI生成画像を使う
- 実在の人物・子どもが写る写真を使う場合は利用規約を必ず確認する

## 5. 品質チェックリスト（完成の基準）

- [ ] スマホで、ファーストビューにキャッチとCTAボタンが両方見える
- [ ] スマホで下部の固定CTAが他の要素と重ならない
- [ ] 3つの画面幅で、横スクロールや文字のはみ出しがない
- [ ] PageSpeed Insights（モバイル）で 90点以上
- [ ] 全画像に alt がある
- [ ] フォームの必須項目が空だとエラーが出る
- [ ] FAQの開閉がキーボードでも操作できる
- [ ] OGP画像が設定されている
- [ ] 色・フォントが上記ルール以外に使われていない
- [ ] 文字と背景のコントラストが十分（本文は 4.5:1 以上）
- [ ] フォームでプライバシーポリシーへの同意が必須になっている

## 6. 作業の進め方（Claude Code へ）

- **一度に全部作らない。** 下記の順番で、1ステップごとに止まって確認を求めること
- 各ステップの終わりに、スマホ幅とPC幅のスクリーンショットを撮って見せること
- 各ステップの完了時に Git でコミットすること
- このファイルのルールと違うことをしたくなったら、先に理由を説明して許可を取ること

### ステップ
1. ファイル構成と、色・フォント・余白の共通設定（CSS変数）を作る
2. ヘッダーとファーストビュー
3. ②お悩み ③特徴
4. ④コース ⑤作品 ⑥レッスンの流れ
5. ⑦保護者の声 ⑧料金 ⑨講師
6. ⑩体験の流れ ⑪FAQ ⑫アクセス ⑬フォーム、フッター、スマホ固定CTA
7. 品質チェックリストを全項目確認して、修正
8. Vercel で公開
